# Pick Your Flavor——按你的條件，找到適合停留的咖啡廳

本專案為 Django 網站開發練習。
以 Django製作的咖啡廳搜尋與比較網站demo，提供條件篩選、關鍵字搜尋、店家文章發布與收藏等功能。

## 專題發想

許多人會到咖啡廳工作或讀書，選擇店家時通常在意是否提供網路、插座，以及有無用餐時間限制。然而，一般搜尋結果往往需要逐篇閱讀介紹，才能確認店家是否符合需求。因此，本網站將這些資訊整理為可查詢的條件，協助使用者更快找到適合的咖啡廳。

## 主要功能與實作

| 功能 | 實作方式 |
| --- | --- |
| 會員登入與註冊 | 使用 Django 的驗證機制處理會員身分。 |
| 發布店家文章 | 使用 `ModelForm` 建立表單，透過 `ImageField` 處理圖片欄位。 |
| 管理自己的文章 | 顯示會員發布的文章，使用 `.save()` 更新、`.delete()` 刪除文章。 |
| 收藏文章 | 建立會員與文章的關聯，以布林狀態判斷是否收藏。 |
| 關鍵字搜尋 | 使用 `icontains` 比對文字，並透過 session 保存查詢狀態。 |
| 條件篩選 | 依城市、網路、是否限時及插座等條件，使用 `Q` 組合查詢條件，並透過 session 保存篩選狀態。 |

## 網站使用流程

1. 從首頁進入咖啡廳列表，瀏覽店家文章與詳細資訊。
2. 輸入關鍵字，或選擇城市與使用條件，縮小查詢結果。
3. 登入後發布、修改或刪除自己的文章，並收藏感興趣的店家。

## 資料設計重點

- `Posting` 記錄店名、城市、地址、價格、網路、限時、插座、使用心得及圖片等資訊，並以外鍵關聯發布會員。
- `Favorite` 關聯會員與文章，記錄該會員對文章的收藏狀態。

## 使用技術

- Django authentication、session
